# DesktopCal 기능 분석

- 분석일: 2026-10-20
- 대상: 사용자 PC에 설치된 DesktopCal(캘린더 목록 / XDiarys). `CalendarTask\` 빌드(3.32.310 업데이트 대상) 기준.
- 방법:
  - 언어 파일(`kor.xml`, `eng.xml`)
  - `resource.zip` 안의 UI XML과 Lua 스크립트(평문)
  - TLB enum
  - DB 스키마(개인 일정 내용은 열람하지 않음)
  - 실행 파일·DLL 문자열
- 한계: 네이티브(C++) 코드는 디컴파일 도구가 없어 열어 보지 못했다. 그래서 일부 항목은 **추정** 또는 **미확인**으로 표시했다.
- DesktopCal 파일은 읽기만 했고 실행하거나 수정하지 않았다.

## 핵심 구조

| 항목 | 내용 | 신뢰도 |
|---|---|---|
| 셀 저장 방식 | 날짜별 **셀 1개 = 여러 줄 자유 텍스트 1개**(`dkcal_mdays_YYYYMMDD`). 한 줄이 한 작업이다. 줄 마크업: `[+]`=완료(취소선), `<font color>`=글자색, `[delay:날짜]`=자동 연기. 셀 배경색과 편집창 크기를 날짜별로 기억하고, 버전 기록도 남긴다. | 확인 |
| 반복·알림·카운트다운 | 셀 텍스트와 별도 테이블(`event_table`)에 저장. 반복 규칙은 RRULE 비슷한 JSON. | 확인 |
| 셀 더블클릭 | 그 날짜 편집 팝업이 셀 위에 열린다. 크기 조절 가능, 최소 160×150. | 확인 |
| 편집 저장 | "저장 및 닫기" 버튼. 포커스를 잃으면 자동 저장. | 추정 |
| 바탕화면 부착 | `dkdockhost.exe`가 `dkdockexplorer.dll`을 **탐색기에 주입**한다. 바탕화면 창(Progman/WorkerW/SysListView32)을 서브클래싱해 그 위에 그리고 마우스 입력을 앱으로 넘긴다. 주입에 실패하면 일반 창 모드로 동작한다. | 확인 |
| 이전/다음 페이지 | 이동 단위는 코드로 확인하지 못했다. 사용자 확인 결과 한 달 단위. | 사용자 확인 |
| 마우스 휠 | 페이지 넘김 흔적이 없다. 셀 내용이 넘칠 때 스크롤만 하는 것으로 보인다. | 추정 |
| 오늘 버튼 | 기본은 숨김. 오늘이 화면에 없을 때만 나타난다. | 표시 조건 추정 |

## 화면

- **표시 모드:** 변동 월 / 전체 월 / 고정 단일 행 / 변동 단일 행
- **옵션:**
  - 최대 행 수, 지나간 주 표시, 주 번호, 월 간격, 그림자, 유리 효과, 제목줄 표시
  - 공휴일(지역 선택)·기념일, 음력·24절기
  - 휴무 요일과 휴무일 배경색, 오늘 테두리 색
  - 셀 글머리표(없음/번호/점), 셀·줄 간격
  - 완료 작업 숨김 / 맨 아래로 정렬, 알림 시간 표시
- **하단 카운트다운 바**(선택)

## 제목줄 버튼 (왼쪽부터)

1. 서브계정 탭: 캘린더 여러 개, 서드파티 캘린더 보기
2. 오늘로(조건부 표시)
3. 🧩 플러그인 메뉴: 메모, 시간표, AI 주간 보고서, Google/Outlook/iCloud/CalDAV 연동, AI(MCP)
4. 📱 모바일 앱 안내(QR)
5. ☁ 로그인 / 동기화 메뉴: 마지막 동기화 시각, 자동 동기화 토글, 서드파티별 동기화 상태. 동기화 중에는 아이콘이 회전한다.
6. 👤 계정 센터: VIP, 계정 설정, 서브계정, 로그아웃
7. ← → 이전/다음 페이지
8. ☰ 추가 옵션
9. 위치·크기 조정 모드에서만: ✓ 적용 / ✕ 취소

## ☰ 메뉴

메뉴 항목 정의 순서이고, 실제 화면 순서는 추정이다.

- 오늘 날짜로 이동, 월 선택(1~12월), 날짜 선택, 이전/다음 페이지
- 최대 행 수
- 예약된 작업 표시/숨기기, 캘린더 열기/숨기기, 위치 및 크기
- 새 메모, 메모 설정, 메모 관리, AI 주간 보고서, 벽지 스킨, 불러오기, 내보내기
- 인쇄, 날짜 선택, 내용 검색
- 계정 설정, 캘린더 설정, 기능 소개, 업데이트, 사용 안내, 후원, 더 많은 소프트웨어, 제품 정보, 로그인, 소프트웨어 종료

## 셀 편집

- **우클릭:** 잘라내기/복사/붙여넣기, 완료·미완료 표시, 미완료 30일 자동 연기(VIP), 글자색, 반복/알림/구독/카운트다운 추가
- **하단 툴바:** 완료 체크, 글자색·배경색(22색 + 사용자 지정, 최근 색 기억), 반복, 알림, 카운트다운, 기록(VIP)
- **효과음:** 완료음(Tick / Ding Dang / Ding Dong / 없음), 완료 단축키
- **반복 종류:**
  - 매일, 근무일, 매주, 매월, 매월 말일, 분기, 매년
  - 음력 매년, 법정 근무일, 에빙하우스 기억곡선
  - 맞춤 일/주/월/연
- **반복 종료 조건:** 영구 / 횟수 / 종료일
- **반복 삭제 범위:** 이번만 / 이후 / 전체
- **알림:** 시각, 미리 알림(당일, 1·2·3·5일 전, 1주 전, 사용자 지정) 여러 개, 우하단 팝업
- **카운트다운:**
  - 유형: 카운트다운 / 생일 / 기념일 / 제전 / 시험
  - 표시 위치: 바탕화면 카드 또는 하단 바
  - 표시 형식: "N일 남음" / "N일 경과"

| 셀 | 글머리표, 간격, 완료 작업 처리, 알림 시간 표시, 자동 연기, 효과음 |
| 글꼴·색상 | 날짜·내용 글꼴, 배경·휴일·오늘 테두리·음력 색, 투명도, 카운트다운 카드 투명도 |

## 플러그인

- **스티커 메모:**
  - 바탕화면 고정 또는 항상 위, 색상
  - 메모 관리자, 단축키로 전체 표시/숨김
- **서드파티 캘린더:** Google / Outlook / iCloud / CalDAV **양방향 동기화**
  - 기존 셀 데이터와 별도 보기(탭)로 표시된다.
  - 셀에 `[HH:MM-HH:MM] 제목` 형식으로 보인다.
  - 날짜를 누르면 그날 일정 목록이 뜬다.
  - 동기화 범위: 과거·미래 1~24개월
  - 자동 동기화 간격: 5(VIP) / 15 / 30 / 60분
- **시간표:** 학기·교시·과목·강의실, 홀/짝 주, 바탕화면 창
- **AI 작업 플랫폼(MCP):**
  - `desktopcal-mcp.exe`가 Claude, ChatGPT, Cursor 같은 AI에 달력·일정·메모 읽기/쓰기 도구를 제공한다.
  - 쓰기 요청은 확인을 거친다.

## 기타

- **인쇄:** 방향, 범위, 미리보기
- **가져오기:** DesktopCal DB, Wallpaper Calendar 3
- **내보내기:** 텍스트, Excel, DB
- **내용 검색:** 키워드, 기간, 완료 여부, 유형, 색상 필터. 결과를 더블클릭하면 해당 날짜로 이동한다.
- **부동 버튼:** 드래그로 이동, 더블클릭으로 달력 표시/숨김
- **벽지 스킨 갤러리**
- **콘텐츠 비밀번호 잠금**
- **구독 푸시:** 공유 링크로 친구에게 일정 보내기

## 유료(VIP) 기능

- 자동·즉시 동기화, 클라우드 영구 보관(무료는 6개월)
- 서브계정
- 미완료 자동 연기
- 셀·메모 버전 기록
- WeChat 알림
- 제목줄 버튼 색 변경
- 전체 기간 내보내기
- VIP 벽지
- 광고 제거
- 서드파티 5분 자동 동기화
- AI 쓰기 할당량 상향
