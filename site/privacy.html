Xetical 개인정보처리방침

시행일: 2026년 10월 20일

수집하는 정보

Xetical은 사용자가 구글 계정으로 로그인해 허용한 경우에만 구글 캘린더 API를 통해 다음 정보에 접근합니다.

  • 캘린더 목록 (이름, 색상, 쓰기 권한 여부)
  • 일정 정보 (제목, 날짜·시간, 장소, 메모)

이용 목적

위 정보는 사용자의 PC 바탕화면에 달력을 표시하고, 사용자가 직접 요청한 일정 추가·수정·삭제를 구글 캘린더에 반영하는 데에만 사용합니다.

저장 및 공유

  • 로그인 정보와 일정 사본은 사용자의 PC에 있는 프로그램 폴더(data)에만 저장됩니다.
  • 개발자를 포함한 어떤 제3자 서버로도 전송하지 않으며, 판매·공유·광고에 사용하지 않습니다.
  • 데이터는 구글 서버와 사용자의 PC 사이에서만 오갑니다.

Google API 서비스 사용자 데이터 정책 준수

Xetical이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

삭제 및 접근 철회

  • 프로그램의 "로그아웃" 메뉴를 누르면 PC에 저장된 로그인 정보와 일정 사본이 삭제됩니다.
  • 구글 계정 > 타사 앱 및 서비스에서 언제든지 Xetical의 접근 권한을 철회할 수 있습니다.

English summary: Xetical accesses the signed-in user's Google Calendar list and events only to display them on the user's own desktop and to apply changes the user requests. Data is stored only on the user's PC and is never sent to any third-party server, sold, or shared. Xetical's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
